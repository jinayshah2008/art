03 / What the code does

    

      
1. Read pixelsThe browser draws your image onto an invisible canvas and reads each pixel's brightness.

      
2. Pick charactersBrightness selects a character from the ramp. Dark areas use dense symbols; bright areas use lighter ones.

      
3. Print a gridEach character becomes one cell in a text grid. A monospace font keeps the columns aligned.
